# AlN seed structures

Seed structures for the AlN atomistic structure benchmark.

All 2 POSCAR files retain their original filenames and bytes. The manifest records source-relative paths, species counts and SHA-256 checksums.

| Case | File | Al | N |
|---|---|---|---|
| seed_unitcell | [AlN_unitcell_ortho.vasp](AlN_unitcell_ortho.vasp) | 4 | 4 |
| seed_psf | [AlN_psf.vasp](AlN_psf.vasp) | 44 | 44 |

AlN_unitcell_ortho.vasp is the perfect orthorhombic seed. AlN_psf.vasp contains the starting prismatic stacking fault. Parts A, B and C use both seeds; part D uses only the perfect seed. Mount only the files permitted for the current part.

This repository contains no answer structures, construction solutions or target coordinates.
